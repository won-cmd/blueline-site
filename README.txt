블루라인 스튜디오 홈페이지 — 관리 안내 (v5: 폴더 자동 인식 구조)
==============================================================

■ 구성
  index.html   : 홈페이지 본체
  assets/      : 이미지·작품 폴더

■ 호스팅
  index.html 과 assets 폴더를 통째로 웹호스팅에 올리면 동작합니다.
  (정적 사이트 — 서버 프로그램/DB 불필요)

■ 작품이 표시되는 두 영역 — featured 한 줄로 결정됩니다
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 하단 [EVERY LINE WE DREW] 그리드
      → 모든 작품 폴더가 자동으로 나타나는 곳 (전 작품)
  · 상단 [NOW ONGOING] 대형 소개
      → info.js 에 featured: true 라고 적힌 작품만 "추가로" 올라가는 곳

  즉, NOW ONGOING 에 올리고 싶으면  featured: true
      그리드에만 두고 싶으면        featured: false
  연재가 끝나 내릴 때는 true → false 로 한 단어만 바꾸면 됩니다.
  (이때 status 를 "완결"로 바꾸면 배지도 함께 바뀝니다)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 새 작품 추가하기 (예: 6번째 작품)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  assets/works/ 안의 숫자 폴더 하나 = 작품 하나 (번호 순서 = 표시 순서)
  현재: 01_deubli 드블리 / 02_fabre 파브르 / 03_gisawang 기사왕님 / 04_beomi 범이 / 05_bupae 부패의 사제

  1) assets/works 안에 새 폴더 "06_영문이름" 을 만든다 (예: 06_newwork)
  2) 그 폴더 이름을 assets/works/folders.js 목록 맨 아래에 한 줄 추가한다
     (folders.js 를 메모장으로 열어 "05_bupae" 아래에  "06_newwork" 처럼)
  3) "_견본(복사용)" 폴더의 info.js 를 복사해 06 폴더에 붙여넣는다
  4) info.js 를 "메모장"으로 열어 따옴표(" ") 안의 글을 바꾼다
     ★ folder: "06_newwork"  ← 반드시 폴더 이름과 똑같이 고칠 것
     ★ 저장할 때 인코딩이 UTF-8 인지 확인 (윈도우10 이상 메모장은 기본이 UTF-8)
  4) 표지 이미지를 cover.jpg 라는 이름으로 넣는다 (세로형 권장)
     - cover.jpg = 하단 [EVERY LINE WE DREW] 그리드 카드에 사용
     - 상단 대형 소개의 커버를 다르게 쓰고 싶으면 main.jpg 를 추가로
       넣으세요 (없으면 cover.jpg 가 양쪽에 쓰입니다)
     - main.jpg 와 똑같은 그림에서 눈만 감은 버전을 main_blink.jpg 로
       넣으면 캐릭터가 몇 초마다 자연스럽게 눈을 깜빡입니다 (선택)
     - 인물이 여러 명이면: 한 명만 감은 버전을 main_blink_a.jpg,
       다른 한 명만 감은 버전을 main_blink_b.jpg 로 "둘 다" 넣으면
       두 인물이 서로 다른 타이밍에 따로 깜빡입니다
       (이때 전원이 감은 main_blink.jpg 도 함께 있어야 합니다)
  5) NOW ONGOING 대형 소개용 일러스트는 01.jpg, 02.jpg, 03.jpg … 순서로 넣는다
     → 번호가 이어지는 만큼 자동으로 인식됩니다 (장수 제한 없음, 최대 40장)
     → 2장 이상이면 좌우 넘김/자동 재생이 저절로 켜집니다
     ★ 번호를 건너뛰면(01, 03) 그 앞까지만 나오니 빈 번호 없이 이어서 붙일 것
     ★ 파일명은 소문자 .jpg (png/jpeg 불가), 가로형 컷이 잘 어울립니다
  저장 후 새로고침하면 사이트에 바로 나타납니다.

  [글만 수정]   해당 폴더의 info.js 를 메모장으로 열어 수정 → 저장
  [그림만 교체] 같은 파일명(cover.jpg, 01.jpg …)으로 덮어쓰기
  [작품 삭제]   폴더를 지우면 사이트에서도 사라집니다
  ※ "_견본(복사용)" 폴더는 사이트에 표시되지 않으니 지우지 말고 두세요

  ※ 이미지 비율은 자유입니다. 어떤 크기를 넣어도
     가운데 기준으로 화면에 가득 차게 자동 표시됩니다.

■ 사이트의 모든 글 수정 — data/site.js 하나로 끝
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  첫 화면 문구, 섹션 제목, CONTACT의 SNS 채널(추가/삭제 가능),
  RECRUIT 문구와 지원 안내, 푸터 사업자 정보와 이메일까지
  전부 data/site.js 를 메모장으로 열어 수정합니다. (UTF-8 저장)
    |  = 줄바꿈      [[글자]] = 파란 강조
  작품별 글(제목/소개/크레딧/링크)은 assets/works/각 폴더/info.js.
  ※ 유일한 예외: 카톡 공유 미리보기 문구(og:title 등)는
    index.html 상단에 있습니다 — 공유 기능 특성상 옮길 수 없습니다.
